A native home
for Pi.

Your Pi sessions, workspace, and tools in one focused native interface. Run on your desktop or keep the engine running headless.

Build from source ↓Check published releases ↗

Source builds are the starting point. Prebuilt Paku downloads are not promised.

One agent, your models.

Paku speaks Pi's native RPC protocol. Configure model providers and credentials in Pi, without juggling separate agent harnesses.

Work stays close.

Local transcripts and attachments by default. No Paku account required. Pi connects to the model provider you choose.

Beyond the chat.

Streaming conversations, tool activity, queues and steering alongside workspace files, terminals, diffs, and themes.

Start with the source.

Install the repository's Rust toolchain, platform build dependencies, and an authenticated Pi CLI (0.85.1 or newer).

Read setup and validation notes ↗
git clone https://github.com/aarsh21/paku.git
cd paku
cargo run -p paku

# No display? Run the engine only.
cargo run -p paku -- headless

Local first. Self-hosting optional.

This fork provides no hosted Paku service. Optional sync infrastructure is retained for operators who configure their own Cloudflare resources and authentication. Synced devices are trusted peers with workspace read/write access.
